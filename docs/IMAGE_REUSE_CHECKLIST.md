# Remaining image reuse evidence

This checklist supplements [the image-rights audit](IMAGE_RIGHTS_AUDIT.md). Public accessibility and publication on another website are not permission records. The user previously requested keeping the portraits and migrating the event photos; the uncertainty is recorded without changing that preference.

| Assets                        | Present evidence                                                          | Needed to close the record                                                                     |
| ----------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Alexander's supplied portrait | Supplied by Alexander for this site                                       | Photographer/rightsholder identity and permission or applicable licence                        |
| Other member portraits        | Public institutional/personal profile sources, listed in the rights audit | Rightsholder reuse permission/licence and confirmation from the person pictured where required |
| Eight COMinDS 2024 photos     | Reused from Alexander's existing blog at his request                      | Photographer/rightsholder confirmation and required credit                                     |
| EuroTUG 2023 group photo      | Reused from Alexander's existing blog at his request                      | Photographer/rightsholder confirmation and required credit                                     |
| FEDDLib artery illustration   | Unchanged image from the official project website                         | Underlying figure/publication and its applicable licence, or explicit reuse permission         |

For each record, capture: asset filename, creator/rightsholder, permission/licence source, date, allowed website use, required attribution and any restrictions. Store written evidence privately where appropriate; only the credit/licence information needs to be public.

The original FBKAN graphic is no longer displayed or included in the build. Its replacement is an original site-native SVG labelled as a conceptual schematic. Scientific figures already verified under CC BY retain their existing source/licence credits. Official software logos retain their documented identification/linking basis; no new blanket licence is asserted.

No messages have been sent to photographers, members or project maintainers. This checklist is an evidence gap, not a claim that the existing use is prohibited or approved.
