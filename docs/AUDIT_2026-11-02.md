# SCaLA website audit, 2 November 2026

For the final 174-page sweep and production CSS follow-up, see the [final audit](FINAL_AUDIT_2026-11-02.md).

This audit covers the current local site after the compact-header, persistent-submenu and Teaching overview changes. Fixes are available at <http://localhost:8080/al-folio/> and remain uncommitted for review. No deployment was performed.

## Findings and fixes

1. **Homepage anchor spacing still allowed for a removed submenu.** Header measurement previously ran only when a submenu existed, leaving the homepage with a fallback offset for both bars. The script now measures the primary header on all pages and records zero submenu height on Home. The fallback also uses zero. Navigation regressions now explicitly include the homepage and its absent submenu.
2. **Three bibliography URLs lost their tilde during LaTeX decoding.** The SciML 2024, Preconditioning 2024 and MAFELAP 2019 links rendered a nonbreaking space in the URL instead of `~`. Their source URLs now encode the tilde as `%7E`. All three rendered destinations return HTTP 200.
3. **Five distinct event destinations had moved.** COMinDS 2023 and the January 2020 SciML workshop now link to Cologne's official workshop archive; NHR links to its current conference page; the numerical-analysis seminar links to TU Delft's current series page. Both ECCOMAS 2022 talk entries now link to the organiser's dated congress announcement. The former ECCOMAS domain's root currently leads to an unrelated sign-in page, so it was not used as a replacement. All replacement destinations were checked and return HTTP 200.
4. **Two retired conference URLs have no verified replacement.** Removed the broken URL buttons for EuroTUG 2019 and DUCOMS 2023, preserving the talk entries and local slides. Original URLs are recorded in the external-link evidence file below.
5. **A duplicated page-spacing rule made the stylesheet harder to maintain.** Consolidated the inner-page margin into one rule, retaining the existing compact spacing.

## Layout review

Reviewed desktop and phone screenshots for Home, Group, Research, Projects, Software, Publications, Talks, Teaching, the master's thesis catalogue, Alexander's profile, Blog and Contact.

- Home retains the full introduction and gallery, without a submenu. Its latest-story/news/talk band remains distinct from research highlights.
- Section menus contain links only; page headings provide the title. Desktop links remain right aligned, while smaller screens retain a single swipeable row. Group categories stay visible while scrolling.
- Teaching now uses open sections and compact rows, rather than two large equal-height boxes. Course metadata, student names and thesis levels remain readable on phones.
- Active member/project cards and compact alumni/archive cards retain their separate purposes. Long titles wrap without spilling out of cards.
- Publications and Talks retain a compact title/search row, expandable older years, and year shortcuts. Status badges remain alongside publication actions. Keyboard expansion, direct fragments and cross-year search work.
- Detail pages retain breadcrumbs for hierarchy. Breadcrumbs and page headings serve different functions; the repeated standalone submenu labels are absent.

No further broad layout rewrite is justified by this pass. Implemented in the follow-up: older course years, short courses/tutorials and completed student projects are collapsed by default with counts and native, keyboard-accessible expand controls. The newest course year remains open; active projects remain visible. Direct catalogue fragments reveal their containing archive.

## External-link evidence

[Detailed link results](AUDIT_EXTERNAL_LINKS_2026-11-02.json) record 446 distinct external HTTP endpoints checked from the initial build. Apparent 404/410 responses were retried with GET.

All eight TU Delft Study Guide destinations returned HTTP 404 to the initial checker but rendered the correct course content in Chromium. Their links were retained. Eight repaired destinations return HTTP 200, and two dead URL buttons were removed. Another 127 endpoints remain inconclusive because of access blocks, timeouts, server responses or failed redirect checks; they are listed individually in the evidence file and have not been labelled broken or replaced with guesses.

The corrected external links do not constitute a re-verification of every publication's scientific metadata or acceptance/publication status.

## Content questions that remain

- **Image rights:** the photographer/rightsholder evidence for portraits, workshop photos and the FEDDLib artery illustration remains incomplete. See [the reuse checklist](IMAGE_REUSE_CHECKLIST.md). No new permission is assumed and no messages were sent.
- **Student project availability:** older project ideas need periodic confirmation from their supervisors. Their listing now uses “Project ideas” and links to contact details for confirming availability. Neither an accessible PDF nor its original date establishes current availability. This audit does not change project availability without evidence.
- **Brief project descriptions:** some member summaries deliberately stay broad where only limited public/source-reviewed information is available. See [member project documentation](MEMBER_PROJECTS.md).

Funded-project classification remains as documented in [the project-status review](PROJECT_STATUS_AUDIT_2026-11-02.md); this audit does not infer that an entire long-running programme ended when a past contribution finished.
