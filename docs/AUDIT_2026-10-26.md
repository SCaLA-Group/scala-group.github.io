# Website audit, 26 October 2026

This audit covers the current customised SCaLA website after the member profiles, shared navigation, gallery and expandable bibliography years were added. The local preview stays running and all changes remain uncommitted.

## Fixes applied

- Improved contrast for year-entry counts and the linked year/tag metadata on blog posts, in both colour themes.
- Made profile, course and blog-archive tables inherit the active text colour. The dark theme had retained dark table text.
- Gave the scrollable academic-appointments table its own accessible landmark name, distinct from the enclosing section.
- Added initials fallbacks for unavailable member portraits, preserving the existing card/profile dimensions. A ResearchGate-hosted portrait denies automated access; the page no longer needs to display a broken image when any portrait fails.
- Replaced the error page's three-second redirect with links to Home, Research, Group and Contact and a suggestion to use search. The old `/people/` alias now redirects immediately to `/group/`. Neither the error page nor the alias is included in the sitemap, and the error page is omitted from search results.
- Removed the opportunities page's dependency on the personal website's empty positions overview. The group page links directly to official TU Delft vacancies and its own contact section.
- Repaired the MALI project's retired-domain link using the [official DOE project overview](https://eesm.science.energy.gov/technical-highlights/mpas-albany-land-ice-mali-variable-resolution-ice-sheet-model-earth-system).
- Placed the gallery directly after the introduction on narrow screens, before publication highlights, matching the content's reading order. Noninitial gallery images now request lazy loading.
- Simplified the repeated SCaLA wording in the footer and standardised the Contact page's Group link label.
- Excluded development tests from generated output.

## Verification

The generated site contains 165 HTML pages. The complete local-link scan found no missing destinations or fragments. A separate production scan also found no local link/fragment or canonical-URL errors; sitemap and robots URLs use the organisation site's root, without local-preview hostnames or `/al-folio/`. Development tests are absent from production output.

Accessibility and overflow were scanned across the site at 320, 768 and 1440 pixels. Older bibliography years were opened for the accessibility recheck. The reported metadata, landmark and dark-table findings were corrected and the affected pages rechecked in both themes. The legacy redirect was verified separately because it intentionally navigates during page loading. The error page was checked separately as well. These automated checks complement the homepage desktop/mobile screenshot review; they do not establish accessibility of every possible interaction or externally hosted content.

All existing browser checks pass: general site controls, profiles, navigation, expandable years, gallery, blog and teaching. The production Jekyll build passes and homepage publication highlights match the bibliography. Production CSS cleanup and representative browser checks are also part of this audit, including both themes and dynamic year controls.

## External-link findings and limits

116 unique external destinations used outside the two bibliography lists were checked. Bibliography records and slide downloads were not all independently rechecked in this pass; earlier repairs remain documented in [the bibliography audit](BIBLIOGRAPHY_AUDIT.md). This distinction avoids claiming that a successful local link scan verifies every external citation or download.

The official StudyGuide course routes return HTTP 404 at the server layer while their JavaScript application renders the correct course description. This was confirmed in the browser, including WI4201 / Scientific Computing. Existing course deep links therefore remain in place. A raw HTTP status alone is insufficient to classify these destinations as broken.

ResearchGate and LinkedIn block some automated requests. Several TU Delft repository and external research-profile endpoints timed out or returned TLS errors. Their links were retained rather than replaced with guessed addresses. Portrait errors now have a user-visible fallback.

Some existing slides/downloads and source acknowledgements still refer to the personal website. The primary navigation and profile content are hosted here; this audit does not claim that every historical download has been migrated.
